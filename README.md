# Bento Boss
VR canteen game built to help kids practise simple money handling.

## About
Made by the **Jellyfish** team, Bento Boss is set in a school stall where players prepare food, handle payments, and manage food stock while serving a queue of students.

## Audience
Ages 7–14.

## Purpose
Teach money counting, change giving, and simple resource management skills.

## Key Features
- VR interactions
- Order system
- Money checking
- Score tracking
- Light and dark mode
- Guide and handbook

## Game Loop
Students order → player serves → student pays → player returns change → repeat. Stock is refilled from matching colour boxes.

Players restock from coloured boxes when food runs out.
- **Yellow:** Fruits
- **Blue:** Drinks
- **Muted Red:** Bento

## Scenes
### Menu
- Sign up
- Log in
- View guide, handbook, and settings
- Log out

### Main Area
The main play area. Players spawn in the stall and serve a queue of students.
## Challenges
- Fufiling orders
- Counting and managing money
- Restocking food items

## Screens
Menu with sign‑up, log‑in, guide, handbook, and settings. The main area places the player into the stall.
